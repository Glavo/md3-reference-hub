### Android Views in maintenance mode

**The Android Views (MDC-Android) M3 library is in maintenance mode.** While it’ll receive critical fixes, Material Android is Compose-first. Migrate to Jetpack Compose to use the latest features. [Read the Compose-first announcement](../../blog/material-is-compose-first.md)
