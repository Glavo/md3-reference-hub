# Radio button

Radio buttons let people select one option from a set of options

## Guidelines

![1 radio button is selected from a list of 4 radio buttons of different ringtones.](../../../assets/images/3615a1d5c5de-mc92xj30-01.png)

_Radio buttons_

## Usage

Radio buttons are the recommended way to allow users to make a single selection from a list of options. 

Only one radio button can be selected at a time.

<video controls src="../../../assets/videos/4264574a51a1-mcelfjb2-GM3_Radio-button_Guidelines_02_IA_v01.mp4" title="1 of 3 languages is chosen using radio buttons. Selecting a language deselects the previous 1."></video>

[Open video](../../../assets/videos/4264574a51a1-mcelfjb2-GM3_Radio-button_Guidelines_02_IA_v01.mp4)

Use radio buttons to:

-   Select a single option from a set
-   Expose all available options

![2 radio buttons are used for allowing or turning off notifications. 2 checkboxes are used for microphone and location access.](../../../assets/images/704088158997-mc93t2tz-03.png)

_Radio buttons are single-select, unlike checkboxes which are multi-select_

![Filter page with 4 sort by options as radio buttons. Relevance is selected.](../../../assets/images/86af9b6f7ab4-mc93whon-04-do.png)

_Use radio buttons when only one option can be selected from a list_

![Meal options page with the Additions item selected, along with 4 nested checkboxes for selecting various toppings. All checkboxes are selected.](../../../assets/images/c304ec777c5d-mc93wr1q-05-do.png)

_Use checkboxes when multiple options can be selected from a list_

Avoid nesting radio buttons or using radio buttons to select multiple options.

![Selected radio button with 2 nested radio buttons.](../../../assets/images/b61208e1b9be-mc93ykkg-06_dont.png)

_Don’t nest radio buttons_

![2 radio buttons selected at once from a list of 3 buttons.](../../../assets/images/b114f28b100a-mc93z4ss-07_dont.png)

_Don’t allow radio buttons to select multiple options_

### Alternate selection controls

Radio buttons are one of several selection controls, which allow people to make choices such as selecting options or switching settings on or off.

Switches and checkboxes are alternative selection controls that can be used to change settings or preferences.

![A selected and unselected switch.](../../../assets/images/0600bb66e9e4-mc942yik-08.png)

_Switches_

![An unselected and selected checkbox.](../../../assets/images/e16a70a09607-mc942but-09.png)

_Checkboxes_

Use radio buttons when there are five or fewer options.

Consider using a drop-down menu instead of radio buttons when it’s important to save space on a screen. However, drop-down menus require additional steps for a person, both in the number of clicks and cognitive effort.

![A filter UI with 1 radio button selected from a list of 3 buttons.](../../../assets/images/61ba86b1402f-mc944w0k-10-do.png)

_Use radio buttons when there are five or fewer options_

![A dropdown menu with a list of 4 options.](../../../assets/images/4e5d176cb238-mc945hgt-11-do.png)

_Consider using a drop-down menu instead of radio buttons when space is constrained_

### Adjacent label text

Always pair radio buttons with an adjacent label describing what the radio button selects.

Because only one radio button can be selected at a time, each choice must have its own label.

<video controls src="../../../assets/videos/0ad406a121a5-mcelh3zd-GM3_Radio-button_Guidelines_13_IA_v01.mp4" title="Checkout page with 2 radio buttons for home and office addresses. The labels are &quot;Home&quot; and &quot;Office.&quot;"></video>

[Open video](../../../assets/videos/0ad406a121a5-mcelh3zd-GM3_Radio-button_Guidelines_13_IA_v01.mp4)

## Placement

Radio buttons are often arranged in stacked layouts.

![Settings page with 3 stacked radio buttons for selecting a language.](../../../assets/images/8071f7ec3273-mc949gf8-14.png)

Radio buttons should be vertically listed and have one option always selected.

![3 radio buttons with 1 option selected.](../../../assets/images/e6fd16520bba-mc94bpsi-16_do.png)

_Radio buttons should always have one option pre-selected_

![2 radio buttons side by side with 1 option selected.](../../../assets/images/c05efaab1862-lwg86p38-16_caution.png)

_Avoid using horizontal radio button lists_

## Behavior

A radio button is successfully selected when a person clicks or taps either the radio button icon or the label.
