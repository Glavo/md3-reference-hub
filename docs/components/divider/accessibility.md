# Divider

Dividers are thin lines that group content in lists or other containers

## Accessibility

Dividers are decorative elements, which have no contrast minimums.

![Divider separating messages in an inbox that are already separated with type styles and spacing is annotated as decorative.](../../../assets/images/9f7130a66683-lv6b63ho-1.png)

_Decorative elements have no contrast minimums_
